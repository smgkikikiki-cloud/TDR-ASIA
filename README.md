# TDR ASIA

Technology, manufacturing and investment news across Asia.

## TDR Megaproject

The repository also contains a separate public interface at `/mega` for Thailand major-project tracking. The interface, data model, and navigation are isolated from TDR ASIA, while a backend event contract (`/api/mega/events`) allows structured project events from TDR ASIA to feed the Megaproject pipeline.

Megaproject tables use the `mega_*` namespace in Supabase.
